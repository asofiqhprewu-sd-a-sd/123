# 🎬 Claude Video Studio (Motion Graphics Studio)

> Автономная программная студия для монтажа технологических эксплейнеров, коротких историй и Shorts/Reels в стиле популярного видео `референс.mp4`.
> Полностью оптимизирована для работы с **Claude Code** и любыми AI-ассистентами.

---

## ⚡ Новые возможности и расширенная библиотека

- **Кинетическая типографика**: фокус на текущем произносимом слове (активное слово яркое и четкое, остальные мягко размыты `blur`).
- **Индикатор удержания (`ProgressBar`)**: тонкая неоновая линия прогресса вверху экрана, удерживающая внимание зрителя до конца ролика.
- **Богатая библиотека компонентов**:
  - `StatCounter` — стремительный анимированный счетчик денег/пользователей (`$0 -> $100,000,000`).
  - `CodeEditor` — окно MacOS-терминала/редактора кода с живым набором синтаксиса.
  - `PhoneMockup` — смартфон с Dynamic Island и всплывающими облачками переписки (Telegram / iMessage).
  - `ComparisonSplit` — карточка батла двух технологий/моделей с горящим бейджем `VS` по центру.
  - `QuoteCard` — неоновая цитата с авторской атрибуцией.
  - `TweetCard` — реалистичный тёмный виджет твита с аватаром и верификацией.
  - `PersonCard` — карточки персоналий с мягким скруглением и подписью имени.
  - `IconHero` — парящие 3D иконки с неоновым свечением и физикой покачивания.
  - `ConnectingDiagram` — анимированные пунктирные связи между сущностями.
  - `CalendarCard` — карточка даты с красной плашкой месяца.
  - `BadgePill` — стильные теги и статусные пилюли.
  - `GridBackground` — технологическая сетка с поддержкой цветовых тем (`dark`, `red`, `blue`, `purple`).
  - `NarratorBadge` — брендовый аватар автора в углу экрана.
- **Расширенный саунд-дизайн**:
  - `sfx/pop.wav` — классический UI-поп
  - `sfx/whoosh.wav` — переход сцен
  - `sfx/cash.wav` — кассовый аппарат и звон монет
  - `sfx/keyboard.wav` — тактильный механический набор кода
  - `sfx/impact.wav` — глубокий трейлерный бас-бум
  - `sfx/glitch.wav` — цифровой глитч
  - `sfx/heartbeat.wav` — напряжённый пульс ожидания
  - `sfx/drop.wav` — плотный бас-дроп
  - `sfx/ping.wav` — звон колокольчика
  - `music/ambient_tech.wav` — фоновый лоу-фай эмбиент бит

## 🚀 Быстрый старт

### 1. Предпросмотр в браузере (Remotion Studio)
```bash
npm run preview
# или дважды кликните: preview.bat
```
Откроется браузер на `http://localhost:3000` с интерактивным плеером Remotion, где можно покадрово просматривать ролик.

### 2. Рендеринг видео в MP4
```bash
python studio.py render demo_how_ai_started
python studio.py render paris_history
python studio.py render showcase_startup
```
